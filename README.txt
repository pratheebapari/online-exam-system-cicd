HOW TO USE THESE FILES (no coding required)
=============================================

1. Go to github.com and create a new PUBLIC repository named:
   online-exam-system-cicd

2. On the repository page, click "Add file" -> "Upload files".
   Drag in ALL the folders from this zip (project1-parameterized-build,
   project2-archive-artifacts, project3-parallel-stages) exactly as they are.
   Click "Commit changes".

3. IMPORTANT: Every Jenkinsfile in this zip has the placeholder text
   REPLACE_WITH_YOUR_USERNAME
   After uploading, open each Jenkinsfile on GitHub (click the file, then
   click the pencil/edit icon), and replace REPLACE_WITH_YOUR_USERNAME
   with your actual GitHub username. Commit the change directly on GitHub.
   (You do this 3 times - once per Jenkinsfile - all in the browser, no
   software needed.)

4. Then follow the step-by-step guide for creating the Jenkins job for
   each project (Project 1 first).
